Notes Blog

December 2025 Productivity App

A notepad web app built for practicing DOM manipulation and local storage.

¿Por qué se hizo? (El Propósito)

Notes Blog fue desarrollado como un proyecto práctico para consolidar conocimientos fundamentales de JavaScript, específicamente la manipulación del Modelo de Objetos del Documento (DOM) y el almacenamiento persistente en el navegador usando LocalStorage.

Desafíos y Desarrollo

El enfoque principal estuvo en crear una interfaz de usuario limpia e intuitiva donde se pudieran agregar, editar y eliminar notas dinámicamente. La persistencia de datos aseguró que las notas del usuario no se perdieran al recargar la página, ofreciendo una experiencia similar a una aplicación real de escritorio.

Tecnologías Utilizadas

HTML5 CSS3 Vanilla JavaScript DOM API
