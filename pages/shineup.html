Shine Up

April 2026 Motivational App

A daily motivational quotes web application aimed to inspire users and keep them focused on their goals.

¿Por qué se hizo? (El Propósito)

Shine Up nació de la necesidad de proporcionar una herramienta sencilla y rápida para obtener motivación diaria. En un mundo lleno de distracciones, el objetivo era crear una plataforma limpia donde el usuario pudiera encontrar citas inspiradoras para empezar su día con energía positiva.

Desafíos y Desarrollo

El principal desafío de este proyecto fue crear una interfaz de usuario atractiva y moderna utilizando únicamente HTML, CSS y JavaScript Vanilla. Se priorizó el rendimiento y las animaciones fluidas para asegurar una excelente experiencia de usuario. Posteriormente, se utilizó Apache Cordova para empaquetar la aplicación web en un archivo APK instalable en dispositivos Android.

Tecnologías Utilizadas

HTML5 CSS3 JavaScript Vanilla Apache Cordova
