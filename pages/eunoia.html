A React.js philosophy quotes app created by Lazaro Meneses to deliver daily reflection, a calm user experience, and a polished mobile-ready experience.

https://eunoia-app-five.vercel.app

"La felicidad de tu vida depende de la calidad de tus pensamientos."

— Marco Aurelio

¿Por qué se hizo? (El Propósito)

Eunoia nació del interés personal por la filosofía y la necesidad de tener un espacio tranquilo para la reflexión diaria. El objetivo era recopilar citas de grandes pensadores estoicos y filósofos clásicos, presentándolas en una interfaz minimalista y libre de distracciones que invitara a la introspección.

Desafíos y Desarrollo

Al ser construido con React.js, el principal desafío fue gestionar correctamente el estado de la aplicación para mostrar citas aleatorias de forma fluida. Además, se implementó un sistema para que los usuarios pudieran guardar sus citas favoritas usando LocalStorage. Finalmente, se integró con Capacitor para empaquetar el proyecto de React como una aplicación nativa para Android (APK).

Tecnologías Utilizadas

React.js CSS3 JavaScript (ES6+) Capacitor
